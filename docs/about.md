# 소개: 직접 실행해 확인한 AI 코딩 도구 기록

Jack의 AI 개발노트는 Codex CLI(코덱스)와 Claude Code(클로드 코드), Python 자동화를 Linux·WSL 환경에서 직접 실행해 확인한 기술 노트입니다.

설정이 막힌 지점에서 실행한 명령과 결과를 남깁니다. 사용한 버전과 확인 범위는 검증 결과 옆에 적고, 옵션과 동작은 공식 문서로 확인할 수 있게 연결합니다. 실습 코드와 검증 기록은 [공개 저장소](https://github.com/kwonseongjae/ai-blog-automation)에 있습니다.

실행한 내용과 문서에서 확인한 내용은 구분합니다. 잘못된 내용은 글 첫머리에 정정 사실을 표시합니다.

## 확인 범위

실행은 Linux 한 환경에서 한 것이 많습니다. Windows와 macOS에서는 결과가 다를 수 있어서 글마다 확인 범위를 적었습니다.

## 방문 통계와 개인정보

방문 통계를 위해 구글 애널리틱스(GA4)를 사용합니다. 글을 어디까지 읽었는지와 블로그 안 링크 클릭을 집계하며, 이름이나 이메일 같은 개인 정보는 수집하지 않습니다.

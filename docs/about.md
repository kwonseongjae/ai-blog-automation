# 소개: 직접 실행해 확인한 AI 코딩 도구 기록

Jack의 AI 개발노트는 Codex와 Claude Code 같은 AI 코딩 도구를 설정부터 직접 실행해 보고, 되는 것과 막히는 것을 기록하는 블로그입니다.

AI 코딩 도구를 처음 쓰는 개발자를 위해 설치와 로그인, 지침 파일, 권한 같은 첫 설정을 다룹니다.

## 이 블로그가 지키는 것

- 하루 최대 한 편만 발행합니다.
- 직접 실행해 확인한 내용만 씁니다. 확인하지 못한 것은 확인하지 못했다고 적습니다.
- 안내 글마다 확인일과 확인 범위를 적고 공식 문서 출처를 둘 이상 답니다.
- 실행에 쓴 코드와 기록은 공개 저장소에 올립니다.
- 틀린 내용을 고치면 글 첫머리에 정정 안내를 표시합니다.

## 글은 이렇게 만듭니다

글은 자동화된 발행 도구로 올립니다. 원고는 발행 전에 검사 규칙을 통과해야 합니다.

검사는 확인일과 공식 출처, 휴대폰에서의 읽기 쉬움, 사람들이 실제로 검색하는 표현이 제목에 있는지를 봅니다.

도구와 검사 규칙은 [공개 저장소](https://github.com/kwonseongjae/ai-blog-automation)에서 볼 수 있습니다.

## 확인 범위

실행은 Linux 한 환경에서 한 것이 많습니다. Windows와 macOS에서는 결과가 다를 수 있어서 글마다 확인 범위를 적었습니다.

## 방문 통계와 개인정보

방문 통계를 위해 구글 애널리틱스(GA4)를 사용합니다. 글을 어디까지 읽었는지와 블로그 안 링크 클릭을 집계하며, 이름이나 이메일 같은 개인 정보는 수집하지 않습니다.
